# Lab 1: HTML & CSS Revision & Animations

This folder contains the practical programs for **Lab 1** of the **Front-End Web Technology (FEWT)** subject at **Darshan University**.

## 🛠️ Programs Included
1. **`lab1_1.html`** - CSS3 Keyframe Animations:
   - Changing background color of a `div` from red to yellow.
   - Moving a `div` in a cyclical path (Left to right, right to bottom, bottom to left, and left to top).
   - Customizing animation properties: 2s delay, infinite iterations, reverse direction, and timing functions.

2. **`lab1_2.html`** - CSS Pseudo-classes & Pseudo-elements:
   - Styling links for `:visited` and unvisited states.
   - Applying special styles to the `::first-line` and `::first-letter` of a paragraph.
   - Customizing background color using `::selection` when text is highlighted.
   - Adding interactive styles using the `:hover` pseudo-class.

3. **`lab1_3.html`** - Personal Portfolio Website:
   - Designed a complete multi-section personal portfolio website using clean HTML and custom CSS styling.

## 🚀 How to Run
You can run these programs by opening any `.html` file directly in your web browser or by using the **Live Server** extension in VS Code.

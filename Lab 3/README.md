## 🛠️ Programs Included
1. **`lab3_1.html`** - JavaScript Popup Box Calculator:
   - Designed a simple interactive calculator using JavaScript popup boxes (`prompt`, `alert`, and `confirm`).
   - Performed basic arithmetic operations (addition, subtraction, multiplication, and division) based on user input.

2. **`lab3_2.html`** - Prime Number Checker:
   - Implemented a JavaScript program to check whether a given number entered by the user is a prime number or not.
   - Displayed the result using an alert box or on the web page.

3. **`lab3_3.html`** - Factorial Generator:
   - Wrote a JavaScript program to find and display the factorial of a given number using loops.

4. **`lab3_4.html`** - Fibonacci Series:
   - Developed a JavaScript program to print the Fibonacci series up to a specified number of terms.

5. **`lab3_5.html`** - Palindrome Checker:
   - Created a JavaScript program to check whether a given number is a palindrome (reads the same forwards and backwards).

6. **`lab3_6.html`** - Armstrong Number Checker:
   - Implemented a JavaScript program to check whether a given number is an Armstrong number.

## 🚀 How to Run
You can run these programs by opening any `.html` file directly in your web browser or by using the **Live Server** extension in VS Code.

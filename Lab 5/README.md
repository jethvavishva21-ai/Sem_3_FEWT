## 🛠️ Programs Included
1. **`lab5_1.html`** - Maximum Number in Array:
   - Wrote a JavaScript program demonstrating the use of arrays to find the maximum number from a given set of elements.

2. **`lab5_2.html`** - Array Sorting (Ascending):
   - Implemented a JavaScript program to read an array from the user and sort the elements in ascending order.

3. **`lab5_3.html`** - Bubble Sort Algorithm:
   - Created a JavaScript program to read an array from the user and sort them using the Bubble Sort algorithm.

4. **`lab5_4.html`** - Quick Sort Algorithm:
   - Developed a JavaScript program to read an array from the user and sort them using the Quick Sort algorithm.

5. **`lab5_5.html`** - Word Search in Sentence Array:
   - Wrote a JavaScript program using a loop that searches for a specific word within a sentence held in an array and returns its index.

## 🚀 How to Run
You can run these programs by opening any `.html` file directly in your web browser or by using the **Live Server** extension in VS Code.

# Front-End Web Technology (FEWT) - Lab Programs (Lab 1 to 28)

This repository contains all the practical lab exercises and projects completed for the **Front-End Web Technology (FEWT)** subject at **Darshan University**.

## 🚀 Technologies Used
- **HTML5 & CSS3** - Web page structure, styling, animations, and pseudo-classes
- **Bootstrap 5** - Responsive web design (Darshan University Home Page Clone)
- **JavaScript (ES6)** - Logic building, popup boxes, arrays, sorting, DOM manipulation, and events
- **jQuery** - DOM traversal, animations/effects, and form validation
- **React.js (Vite)** - Components, Props, State (`useState`), Effects (`useEffect`), Routing, and CRUD operations

---

## 📂 Detailed Lab Structure & Instructions

### 🌐 Part 1: HTML, CSS, Bootstrap & JavaScript (Lab 1 to Lab 13)
This section contains all the core web development practicals including styling, animations, responsive design, popup-based JavaScript logic, arrays, and jQuery operations.

* **Lab 1:** HTML/CSS Revision, Keyframe Animations, Pseudo-classes/elements, and Personal Portfolio Website.
* **Lab 2:** Bootstrap 5 Responsive Web Design (Darshan University Homepage Clone).
* **Lab 3 & 4:** Core JavaScript Programs using Popup Boxes (Calculator, Prime, Factorial, Fibonacci, Palindrome, Armstrong, Factors, Number to Words, String Vowel operations, and Patterns).
* **Lab 5 & 6:** JavaScript Array Operations, Sorting (Bubble Sort, Quick Sort), Searching, and Array Methods (`push`, `pop`, `shift`, `unshift`, `splice`, `sort`).
* **Lab 7 to 11:** DOM Manipulation, Dynamic Elements, and Event Handling.
* **Lab 12 & 13:** jQuery Operations, Effects (Fade, Slide, Hide/Show), DOM Traversal, Event Binding, and Form Validation.

👉 **How to run Lab 1 to 13:**
You can directly open any `.html` file inside your web browser or use the **Live Server** extension in VS Code.

---

### ⚛️ Part 2: React.js Practicals (Lab 14 to Lab 28)
This section contains modern front-end practicals built using **React.js (Vite)**, covering component structures, hooks, routing, API integration, and CRUD operations.

* **Lab 14 to 28:** React Components, Props, State Management (`useState`), Side Effects (`useEffect`), Controlled Forms, Navigation/Routing, MockAPI integration, and practical exercises.

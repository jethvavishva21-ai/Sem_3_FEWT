# Front-End Web Technology (FEWT) - Lab Programs (Lab 1 to 28)

This repository contains all the practical lab exercises and projects completed for the **Front-End Web Technology (FEWT)** subject at **Darshan University**.

## 🚀 Technologies Used
- **HTML5 & CSS3** - Web page structure, styling, animations, and pseudo-classes
- **Bootstrap 5** - Responsive web design (Darshan University Home Page Clone)
- **JavaScript (ES6)** - Logic building, popup boxes, arrays, sorting, DOM manipulation, and events
- **jQuery** - DOM traversal, animations/effects, and form validation
- **React.js (Vite)** - Components, Props, State (`useState`), Effects (`useEffect`), Routing, and CRUD operations

## 📂 Detailed Lab Structure & Instructions

### 🌐 Part 1: HTML, CSS, Bootstrap & JavaScript (Lab 1 to Lab 13)
This section contains all the core web development practicals including styling, animations, responsive design, popup-based JavaScript logic, arrays, and jQuery operations.

## 📚 Lab Index & Overview

### 🛠️ Lab 1: HTML & CSS Revision & Animations
- **CSS3 Keyframe Animations:** Background color transitions, cyclical `div` movements (left to right, right to bottom, bottom to left, left to top), and customized properties (delays, infinite iterations, reverse direction, timing functions).
- **Pseudo-classes & Pseudo-elements:** Styling links (`:visited`, unvisited), paragraph styling (`::first-line`, `::first-letter`), text selection (`::selection`), and interactive `:hover` effects.
- **Personal Portfolio Website:** A multi-section responsive portfolio website built with clean HTML and custom CSS.

### 🎨 Lab 2: Bootstrap Revision
- **Darshan University Homepage Clone:** Designed a responsive clone of the Darshan University official home page utilizing Bootstrap utility classes, grids, and components.

### 💬 Lab 3: JavaScript Popup Boxes & Basic Programs
- **Popup Box Calculator:** A simple interactive calculator implemented using JavaScript popup boxes (`prompt`, `alert`, `confirm`).
- **Mathematical & Logical Programs:** Prime number checker, factorial generator, Fibonacci series printer, Armstrong number checker, and palindrome checker.

### 🔢 Lab 4: Basic JavaScript Programs & String Manipulation
- **Factors & Range Primes:** Programs to print factors of a number and find prime numbers within a given range.
- **Patterns & GCD:** Displaying custom text/symbol patterns and computing the Greatest Common Divisor (GCD) of two numbers.
- **Digit Separation & Exponentiation:** Taking a 2-digit number, separating its digits, and raising the first digit to the power of the second digit.
- **Number to Words:** Converting a 0–999 number from a popup box into words with proper error handling ("out of range", "not a number").
- **String Vowel Operations:** Finding the first and last occurrence of the vowel "a" in a given word and extracting the substring between them (e.g., `ajanta` $\rightarrow$ `jant`).

### 📦 Lab 5: Basic Array Programs in JavaScript
- **Maximum Number & Sorting:** Finding the maximum number in an array and sorting elements in ascending order.
- **Sorting Algorithms:** Implementation of **Bubble Sort** and **Quick Sort** algorithms.
- **Word Search:** Searching for a specific word within a sentence stored in an array and returning its index.

### 🖥️ Lab 6: Rendering Array Elements in JavaScript
- **Faculty & Student Directory:** Displaying lists of faculty members and students stored in arrays.
- **Array Methods Demonstration:** Hands-on usage of `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, and other native array methods.
- **Product Catalog:** Rendering a product list dynamically using JavaScript arrays.

### 📝 Lab 7: Form Validation in JavaScript
- **Graphical Calculators:** Basic and Scientific graphical calculators built using HTML and JavaScript.
- **Static Login Page:** A clean authentication page interface with validation.
- **Comprehensive Form Validation:** Validating user inputs according to strict criteria:
  - Username: Minimum 8 characters.
  - Password: 8–12 characters, containing at least 1 digit and 1 special character.
  - Password matching confirmation.
  - Age > 18 calculated dynamically from Date of Birth.
  - Enrollment Number: Exactly 11 digits.
  - Email format verification.

### ⚡ Lab 8: Document Object Model (DOM) Methods
- **Dynamic Styling & Events:** Changing background colors on button clicks, and recognizing mouse, keyboard, and form events.
- **Element Property Modification:** Dynamically updating attributes and properties of HTML elements.
- **Student Registration Form:** Fully functional registration form with DOM-based validation.
- **Interactive Mouse & Key Event Handlers:** 
  - Heading color toggling on mouseover/mouseout.
  - Live date/time display via button clicks.
  - Background color switching based on button labels (`red`, `green`).
  - Vowel key detection (`a`, `e`, `i`, `o`, `u`) and key-release background changes (`blue`).

### 🚀 Lab 9: ES6 Features in JavaScript – Part 1
- **Callbacks:** Demonstrating asynchronous callback functions.
- **Variable Scoping:** Clear demonstration of differences between `let`, `const`, and `var`.
- **Default Parameters:** Using default values in function parameters.
- **Mini-Game:** Developed a functional Snake game using JavaScript.

### 🔄 Lab 10: ES6 Features in JavaScript – Part 2
- **Arrow Functions:** Syntax and usage of concise arrow functions.
- **Advanced Mouse Events:** Distinguishing left-click vs. right-click events on the browser window.
- **Checkbox Value Aggregator:** Handling a list of checkboxes (e.g., roll numbers) and displaying selected values dynamically in a comma-separated format.

### 📦 Lab 11: ES6 Features in JavaScript – Part 3
- **Classes & Objects:** Creating and instantiating ES6 classes.
- **Spread Operator:** Spreading arrays and objects efficiently.
- **`for...of` Loops:** Iterating over iterable objects cleanly.
- **Destructuring:** Array and object destructuring techniques.

### ⚡ Lab 12: jQuery Operations
- **Effects & Animations:** Fading objects, sliding up/down/toggle images, and toggling visibility.
- **DOM Manipulation:** Setting `<h1>` content, retrieving textbox values, and appending new list items or table rows dynamically.
- **Traversing & Selectors:** Changing child element styles, hiding sibling elements, and targeting classes/IDs (`myDiv`, `myEle`).
- **Event Handling:** Click events, blur validation for Darshan enrollment numbers, focus effects on input fields, mouseenter styling, and console logging mouse coordinates.

### 🗃️ Lab 13: CRUD Operations on Static Array using jQuery
- **Complete CRUD Application:** Performing Create, Read, Update, and Delete operations on a static array containing structured records (FirstName, LastName, Age, Semester, RollNumber, ImagePath, etc.) using jQuery and dynamic HTML rendering.

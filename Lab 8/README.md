### ⚡ Lab 8: Demonstrate Document Object Model Methods in JavaScript
1. **`lab8_1.html`** - Background Color Changer:
   - Wrote a program to change the background color on the click of a button.
2. **`lab8_2.html`** - Mouse Event Recognizer:
   - Wrote a program to recognize which mouse event is fired.
3. **`lab8_3.html`** - Keyboard Event Recognizer:
   - Wrote a program to recognize which keyboard event is fired.
4. **`lab8_4.html`** - Form Event Recognizer:
   - Wrote a program to recognize which form event is fired.
5. **`lab8_5.html`** - HTML Element Property Modification:
   - Wrote a program to demonstrate changing properties of HTML elements using JavaScript.
6. **`lab8_6.html`** - Student Registration Form:
   - Wrote a program to prepare a student registration form and validate it using JavaScript.
7. **`lab8_7.html`** - Array CRUD Operations:
   - Wrote a program to perform CRUD operations on an array using HTML and JavaScript.
8. **`lab8_8.html`** - Interactive Mouse & Time Events:
   - Handled mouseover/mouseout events on headings (turning yellow/black), click events for date/time display, and color-changing buttons (`red` and `green`).
9. **`lab8_9.html`** - Vowel & Key Code Events:
   - Handled keyboard events to display key codes, announce when a vowel (`a`, `e`, `i`, `o`, `u`) is pressed, and change background color to blue on key release.

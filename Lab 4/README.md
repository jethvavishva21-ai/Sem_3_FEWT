## 🛠️ Programs Included
1. **`lab4_1.html`** - Factors of a Given Number:
   - Wrote a JavaScript program to find and display all the factors of a given number.

2. **`lab4_2.html`** - Prime Numbers in a Range:
   - Implemented a JavaScript program to find and print all prime numbers between a given range of numbers.

3. **`lab4_3.html`** - Number & Symbol Patterns:
   - Developed JavaScript programs to display various number and symbol patterns (pyramids, triangles, etc.).

4. **`lab4_4.html`** - Greatest Common Divisor (GCD):
   - Created a JavaScript program to compute the Greatest Common Divisor (GCD) of two numbers.

5. **`lab4_5.html`** - Digit Separation & Exponentiation:
   - Wrote a JavaScript program to take a 2-digit number, separate its digits, and multiply the first digit by itself for the second-digit times (e.g., 23 $\rightarrow$ 2 multiplied by itself 3 times).

6. **`lab4_6.html`** - Number to Words Converter:
   - Developed an HTML page with JavaScript that takes a number (0-999) from a popup box and displays it in words, with error handling for "out of range" or "not a number".

7. **`lab4_7.html`** - String Vowel Operations:
   - Created a JavaScript program to find the position of the first and last occurrence of the vowel "a" in a given word and return the substring between them (e.g., `ajanta` $\rightarrow$ `jant`).

## 🚀 How to Run
You can run these programs by opening any `.html` file directly in your web browser or by using the **Live Server** extension in VS Code.

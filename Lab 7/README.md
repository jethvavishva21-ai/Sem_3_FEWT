### 📝 Lab 7: Implement Validation of Form Fields in JavaScript
1. **`lab7_1.html`** - Basic Graphical Calculator:
   - Wrote a program to create a basic graphical calculator using HTML and JavaScript.
2. **`lab7_2.html`** - Static Login Page:
   - Wrote a program to create a static login page with validation.
3. **`lab7_3.html`** - Scientific Graphical Calculator:
   - Wrote a program to create an advanced scientific graphical calculator using HTML and JavaScript.
4. **`lab7_4.html`** - Comprehensive Form Validation:
   - Validated user data from an HTML form based on multiple constraints:
     - Username: minimum 8 characters.
     - Password: 8–12 characters, containing at least 1 digit and 1 special character.
     - Password matching confirmation.
     - Age > 18 (calculated from Date of Birth).
     - Enrollment number: exactly 11 digits.
     - Valid email format.
